Codes RP

Nous proposons quelques codes en libre service, qui sont optimisés spécialement pour PUMPKINS ; vous ne devez pas les utiliser ailleurs. Vous pouvez les personnaliser à votre guise. Nous vous demandons simplement de vérifier que vos codes soient lisibles sur les trois thèmes (contrastés, pas flashy, avec une police de taille minimale de 15px).

Note

Nous proposons deux codes RP modulables, un code de fiche de relations, ainsi qu'un code de lettre, et un code de SMS.

Textes

  • Gras : <ppkb>texte</ppkb>
  • Italique : <ppki>texte</ppki>
  • TW avec animation : <tw>texte</tw>
  • TW sans animation : <ppktw>texte</ppktw>
  • Sorcier : <bgsor>texte</bgsor>, <bsor>texte</bsor>, <isor>texte</isor>
  • Familier : <bgfam>texte</bgfam>, <bfam>texte</bfam>, <ifam>texte</ifam>
  • Humain : <bghum>texte</bghum>, <bhum>texte</bhum>, <ihum>texte</ihum>
  • Reliquaire : <bgrel>texte</bgrel>, <brel>texte</brel>, <irel>texte</irel>
  • Éveillé : <bgeve>texte</bgeve>, <beve>texte</beve>, <ieve>texte</ieve>
